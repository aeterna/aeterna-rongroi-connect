# aeterna-rongroi-connect

**Status: private, pre-spike.** Rongroi Connect is a planned companion to
[aeterna-rongroi](https://github.com/aeterna/aeterna-rongroi): a Windows app that, with the player's consent,
sends a rongroi report to the one FiveM server it was paired with. The offline rongroi program stays
unchanged and sends nothing.

Nothing here is released. The repository becomes public (GPL-3.0-or-later) at 0.1.0.

Rules that apply to every rongroi product: evidence, never a verdict; no "clean" or "verified" label;
no automatic ban. See aeterna-rongroi `AGENTS.md` and `docs/adr/0002`, `0040`.
